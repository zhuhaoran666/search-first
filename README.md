# Search First

一个帮助用户精炼想法，再检索和核验现有方案、资料与资源的 Codex skill。

网络上已有可用内容时，优先找到真实对象和原始来源。模型用于理清需求、构造查询、概括与比较证据，不用自制内容冒充检索结果。

## 工作流程

1. **精炼 idea**：提取目标、场景、所需结果和明确约束，将模糊想法整理成一两句可纠正的检索说明。需求清楚时直接检索。
2. **查找现成内容**：选择适合对象的入口，根据真实结果中的正式名称、同义词和来源线索调整查询。
3. **打开并核验**：核对原文是否支持结论、资源是否满足条件，以及版本、格式、许可和访问状态。
4. **用证据反馈 idea**：说明哪些内容可以复用、哪里仍有差距，并给出有依据的收敛建议。

检索到页面介绍、读到正文、取得文件和实际运行分别报告。找不到时说明缺口；“未找到”不等于“不存在”。

## 适用范围

适合寻找现有方案与案例、原文出处、模板、图片素材、教程、开源项目、数据集或精确文件。也适合先理清一个想法，再查网上已有的实现。

纯原创生成、本地编辑与计算、完整系统性文献综述应使用相应工作流。用户明确要求原创或适配时，保留其意图。

## 使用示例

```text
$search-first 我想把读过的文章关联起来，写作时能快速找回相关内容。
先帮我理清需求，再找现成工具和使用案例，说明哪些部分能直接复用。
```

```text
$search-first 帮我找免费、可编辑的科研流程图 PPT 模板，要求提供 PPTX。
请打开来源核实文件格式和使用许可，不用自己制作。
```

## 安装

将本仓库的内容放入 Codex 个人技能目录下的 `search-first/` 文件夹，使其中直接包含 `SKILL.md`；也可使用 `skill-installer` 从本仓库安装。

安装后可用 `$search-first` 显式调用；技能也保留自动发现能力。

## 工具能力与限制

本技能提供检索工作流，不自带搜索引擎、账号或付费数据库。实际覆盖范围取决于当前环境可用的搜索、网页读取、浏览器和连接器工具。

登录、付费、地域或访问权限可能限制核验。工具不可用或内容不可读时，应如实说明，不能声称已检索或已验证。普通检索不会自动安装工具、购买服务或绕过访问控制。

## 文件说明

- `SKILL.md`：触发条件、idea 精炼、检索、核验和交付规则。
- `references/query-strategies.md`：查询改写、来源追踪和检索受阻时的恢复策略，按需读取。
- `agents/openai.yaml`：Codex 界面的技能名称和简短说明。
