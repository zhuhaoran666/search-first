# Search First

一个帮助用户精炼想法，判断何时检索、何时生成、何时结合两者，并完成所需结果的 Codex skill。

需要真实对象与外部依据时检索，需要原创、设计、改写与实现时生成；两者都有时，核实所需依据并完成创作或适配。保留 `search-first` 名称，不要求所有任务都先搜索，也不禁止原创。

## 如何判断

| 需求 | 路径 |
| --- | --- |
| 原文、出处、真实照片、现成文件或指定版本示例 | 检索实际对象并核验 |
| 依赖当前信息、外部记录或需核实的事实 | 检索所需依据，再据此回答或制作 |
| 原创文本、概念图、设计或代码，信息已足够 | 直接生成，使用适合的制作工具 |
| 根据用户提供的充分材料改写、总结或转换 | 基于材料生成或本地处理 |
| 基于真实资料做新作品，或复用后定制 | 结合检索与生成，交付完成的结果 |

尊重用户明确的“只找现成”“不要联网”“原创”等范围。不把自制内容冒充原物，不让生成替代事实核验，也不把生成任务停在链接清单。

## 工作流程

1. **精炼 idea**：提取目标、场景、所需结果和明确约束。需求清楚时直接执行。
2. **选择路径**：判断哪些部分需要真实来源或现有资源，哪些部分需要新内容。
3. **检索与制作**：按依赖核验来源、复用现有内容、生成原创部分或适配成品。
4. **反馈与交付**：根据来源证据、草稿或原型揭示的差距收敛 idea，交付用户需要的结果。

检索到页面介绍、读到正文、取得文件和实际运行分别报告。找不到时说明缺口；“未找到”不等于“不存在”。

## 适用范围

适合判断一个想法应当找现成方案、直接创作还是结合两者；也适合原始来源定位、可复用资源检索，以及基于真实资料制作新结果。

复杂文档、图片、图表、代码实现或系统性研究使用相应的专门工具和工作流。本技能负责选路与衔接，保留用户的创作意图。

## 使用示例

```text
$search-first 我想把读过的文章关联起来，写作时能快速找回相关内容。
先帮我理清需求，再找现成工具和使用案例，说明哪些部分能直接复用。
```

```text
$search-first 帮我找免费、可编辑的科研流程图 PPT 模板，要求提供 PPTX。
请打开来源核实文件格式和使用许可，不用自己制作。
```

```text
$search-first 根据我给的提纲和数据做一页说明图。
资料足够就直接制作；需要外部依据的地方先核实，再完成成品。
```

## 安装

将本仓库的内容放入 Codex 个人技能目录下的 `search-first/` 文件夹，使其中直接包含 `SKILL.md`；也可使用 `skill-installer` 从本仓库安装。

安装后可用 `$search-first` 显式调用；技能也保留自动发现能力。

## 工具能力与限制

本技能提供路径判断、检索核验与制作衔接规则，不自带搜索引擎、账号或付费数据库。实际检索和制作能力取决于当前环境可用的搜索、网页读取、浏览器、连接器与内容制作工具。

登录、付费、地域或访问权限可能限制核验。工具不可用或内容不可读时，应如实说明，不能声称已检索或已验证。普通检索不会自动安装工具、购买服务或绕过访问控制。

## 文件说明

- `SKILL.md`：触发条件、idea 精炼、检索/生成判断、制作衔接、核验和交付规则。
- `references/query-strategies.md`：路径判断示例、查询改写、来源追踪和检索恢复策略，按需读取。
- `agents/openai.yaml`：Codex 界面的技能名称和简短说明。
